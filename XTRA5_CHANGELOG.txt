========================================
Xtra5 1.39.1 (2026-11-14)
Based on official Xtra 0ab697d (Xtra 2.60.10)

Fixed
- Settings > Restore settings is now reliable (official Xtra issue):
  - With both backup files picked, the settings file is always restored before the database.
    Restoring the database restarts the app, so the settings could be skipped if they came
    second.
  - Restoring only the settings file now restarts the app too, so the running app can't save
    its old settings back over the restored ones.

Xtra5 1.36.0 (2026-11-14)
Based on official Xtra 0ab697d (Xtra 2.60.10)

New
- Default highlight group: open a group, tap Group... and choose "Set as default group"
  (or "Unset default group"). It is marked "(default)" in the list.
- Long-press a message or a name in chat to add that chatter to the default group, or take
  them out if they're already in it. Someone in another group or ungrouped moves to it.
  Shows "No default group set" if there isn't one. Grey "replying to" lines are ignored.
- Long-press an emote in chat to put its text into the chat input (not sent). The input
  appears if it was hidden.

Changed
- Highlight panels beside the chat in landscape are now centred in the space left of the chat
  and up to 90% of its width, instead of hugging the chat.
- Highlighted users list in landscape shows two columns: Groups | Ungrouped. Group members
  also show in two columns, and the color picker uses its wide three-column layout whenever
  there's room.

Behind the scenes
- Renaming the default group keeps it the default; deleting it clears the default.

Xtra5 1.29.0 (2026-11-13)

New
- Highlight groups (Highlighted users, from the player button or Settings): "New group" creates
  a named group with a color; every user added to it uses the group's color, and changing the
  group color recolors all of them (live in the chat while picking). Groups can be renamed or
  deleted (keeping their users as ungrouped, or removing them too).
- Users can be moved between groups and Ungrouped. The group color is master: giving a grouped
  user their own color moves them to Ungrouped with that color; moving them back into a group
  makes them use the group color again. A user is in one place at a time.

Changed

  move, remove).

Xtra5 1.23.0 (2026-11-12)
Based on official Xtra 0ab697d (Xtra 2.60.10)

Changed
- Live streams ignore pauses from earbuds / headphones (taking them out, putting them in the
  case, taps) and from Android's system media controls, so a live stream keeps playing. The TV

- Up: shows the controls and holds the seek bar at the current position, like a finger on the
  marker. Left / Right then move the marker by Seek bar jump (1-10% of the video length,
  slider, default 5%) without seeking yet. OK jumps to the marker. Back cancels, and so does
  6 seconds without a button press. On live streams, Up just shows the controls.
- Down: opens the Chapters menu on VODs that have chapters.
- Arrow keys still work normally while typing in chat or with the player minimized.
