Xtra5 changelog (newest first)

========================================
Xtra5 1.23.0 (2026-11-12)
Based on official Xtra 0ab697d (Xtra 2.60.10)

Changed
- Live streams ignore pauses from earbuds / headphones (taking them out, putting them in the
  case, taps) and from Android's system media controls, so a live stream keeps playing. The TV
  remote, on-screen controls and the notification still pause, and play from earbuds still
  works. VODs and clips pause from earbuds as normal. Replaces 1.22.0's "2 seconds around a
  disconnect" rule, which missed earbuds that pause before disconnecting.
- Unpausing a paused live stream (any way) jumps straight to live instead of carrying on from
  where it was paused (ExoPlayer seeks to live; the MediaPlayer engine restarts the stream).
========================================
Xtra5 1.22.0 (2026-11-12)
Based on official Xtra 0ab697d (Xtra 2.60.10)

Changed
- Videos keep playing when Bluetooth or wired headphones / IEMs disconnect; audio continues on
  the device's speakers. Android's "audio becoming noisy" pause is always off (official Xtra's
  switch for it no longer has any effect), and a headset's own "pause" signal sent within about
  2 seconds of it disconnecting is ignored, or undone if it arrives just before the disconnect.
  Pausing from the remote, screen or notification at other times works as normal.
========================================

Fixed

Xtra5 1.21.0 (2026-11-12)
Based on official Xtra 0ab697d (Xtra 2.60.10)

New
- Minimizing a stream or VOD while using the app automatically refreshes every section of the
  screen behind it (like the refresh button), once the minimize animation has finished.
- Coming back to the app after leaving it with no video on screen (home screen, another app,
  screen off; not picture-in-picture) automatically reloads an open live stream, minimized or
  full-size, like Restart player. VODs and clips are not reloaded.

Xtra5 1.19.0 (2026-11-12)

New

Xtra5 1.18.0 (2026-11-11)
Based on official Xtra 0ab697d (Xtra 2.60.10)

New
- Refresh button in the top bar, between search and the ⋮ menu, on every screen with the search
  button (Following, Popular, Games, Saved, category pages). One press reloads every loaded
  section of that screen (e.g. Live, Videos and Channels), the same as pulling down to refresh.
  Sections not opened yet load fresh when first opened. Works with the D-pad.
- TV mode shortcut: holding OK with no video open, or with the video minimized, does the same
  refresh of every loaded section ("Refreshing" message). This replaces holding OK on a video
  or clip card to open Download in that state; use the card's ⋮ menu to download instead.
  With a live stream full-size, holding OK still reloads the stream.

Xtra5 1.7.0 (2026-11-11)
Based on official Xtra 0ab697d (Xtra 2.60.10)

New
- Chat appearance (Settings > Chat > Chat appearance):
  - Message spacing: 1-50 px of space between chat messages (default 4).
  - Lines between messages: a thin line in the middle of the gap. Off by default.
  - Chat font: Default, Regular, Light, Medium, Condensed or Condensed medium
    (Android's built-in Roboto family, as used by S0undTV).
  Changes apply the next time the chat opens.
- Long-press Back on the remote closes the stream or VOD completely, like swiping the player
  away. Works with the player full-size or minimized. Part of TV mode shortcuts. A short press
  of Back is unchanged, and while the seek bar is held Back still just cancels.
- Rewind / fast-forward animation for TV mode Left/Right skips: a large icon with the amount
  ("10s") at the left center (rewind) or right center (fast-forward) of the video. Quick
  presses add up ("20s", "30s") and it fades 0.7 seconds after the last press.

Changed
- Color picker fits without scrolling: in landscape the wheel sits on the left with the other
  controls on the right; in portrait the wheel shrinks to fit smaller screens.

Xtra5 1.6.0 (2026-11-11)
Based on official Xtra 0ab697d (Xtra 2.60.10)

New
- TV mode shortcuts for TV remotes, Bluetooth remotes, keyboards and game controllers,
  on TV boxes, phones and tablets (Settings > Player > TV mode shortcuts). Off by default.
- Shortcuts work in the full-size player while the on-screen controls are hidden.
  With the controls showing, the D-pad moves between buttons as normal.
- Left / Right: jump back / forward by a fixed Seek step (5-60 seconds, slider, default 10).
  Each press jumps once; holding the button counts as one press. Not on live streams.
- Up: shows the controls and holds the seek bar at the current position, like a finger on the
  marker. Left / Right then move the marker by Seek bar jump (1-10% of the video length,
  slider, default 5%) without seeking yet. OK jumps to the marker. Back cancels, and so does
  6 seconds without a button press. On live streams, Up just shows the controls.
- Down: opens the Chapters menu on VODs that have chapters.
- Arrow keys still work normally while typing in chat or with the player minimized.

Behind the scenes
- Changelog: this file holds the full history, and every release includes its entry as
  Xtra5-X.Y.Z-changelog.txt next to the APK and as the release description.
- Automatic builds write their own entry listing the official Xtra changes they include.
- CLAUDE.md added with the project's working rules: confirm plans before coding, test builds
  on wip-* branches, changelog entry for every version.

Xtra5 1.3.0 (2026-11-11)
Based on official Xtra 0ab697d (Xtra 2.60.10)

New
- Xtra5 keeps up with official Xtra automatically: a GitHub workflow checks once a day, merges
  any official changes, bumps the FIX number, builds and publishes a new Xtra5 release with
  all custom features included.
- The in-app updater installs new Xtra5 builds: "Update available" > Yes > install. Checks
  daily when the app opens (Settings > Update settings).

Changed
- Replaced 1.2.0's notify-only dialog with the updater. Official Xtra changelog stays in Settings.

Fixed
- First automatic build failed to publish: the release step tried to target the official Xtra
  repository (GitHub refused it; nothing was created there). The workflow now only ever writes
  to the Xtra5 repository. Fixed before 1.3.0 was released.

Behind the scenes
- Workflow never pushes to master, so official Xtra's own workflow never runs on this repo.
========================================
Xtra5 1.2.0 (2026-11-11)
Based on official Xtra 0ab697d (Xtra 2.60.10)
